# GCP Enterprise Security Lab

GCP 보안 설정을 점검하고, 변경 전후의 접근 결과를 확인하는 개인 실습 기록이다. Google Skills 랩과 로컬 환경을 활용해 네트워크 접근통제, IAM, 취약점 관리, 감사로그 분석을 다룬다.

설정을 바꾸는 이유와 결과를 함께 기록해 남기는 데 중점을 둔다. 실습별로 필요한 접근을 정리하고, 현재 설정과 비교한 뒤, 변경 내용과 검증 결과를 기록한다.

## 실습 환경

Google Skills에서 제공하는 임시 프로젝트(Lab)를 사용한다. 실습마다 환경이 분리되므로 설정과 로그를 수집해 각 사례 폴더에 정리한다. 의존성 분석과 패치·재검사는 로컬 환경에서 진행할 계획이다.

각 실습은 독립된 사례이다. 하나의 상시 운영 GCP 환경에 모든 기능을 통합하는 구성은 아니다.

## 기록 방식

실습별로 다음 질문에 답할 수 있도록 정리한다.

1. 어떤 자산을 검토하며, 어떤 접근이 필요한가?
2. 현재 설정에서 확인한 문제는 무엇인가?
3. 무엇을 바꿨고, 그 이유는 무엇인가?
4. 변경 후 필요한 기능과 접근 제한을 어떻게 확인했는가?
5. 아직 확인하지 못했거나 추가로 개선할 부분은 무엇인가?

설정 파일, 명령 출력, 접속 결과를 판단의 근거로 활용한다. 오류가 발생하면 관찰한 현상과 확인한 원인을 구분해 기록한다.

## 저장소 구성

| 경로 | 내용 |
|---|---|
| `labs/` | 실습별 소개, 검토 문서, 증적, 코드 |
| `docs/` | 공통 점검 기준, 위험평가 방식, 실습별 위험 현황 |
| `templates/` | Finding과 재점검 기록 등에 사용할 문서 양식 |
| `scripts/` | 여러 실습에서 재사용하는 수집·비교·비식별화 코드 |

각 실습 폴더는 아래 구조를 기본으로 하며, 필요한 항목부터 추가한다.

| 경로 | 내용 |
|---|---|
| `README.md` | 실습 개요, 진행 상태, 주요 결과 |
| `reports/` | 범위, 현황, 발견한 문제, 변경 이력, 검증 결과 |
| `evidence/` | 공개용 설정·시험 결과·로그 발췌 |
| `diagrams/` | 구성도와 접속 경로 |
| `scripts/` | 해당 실습에서 사용하는 코드 |
